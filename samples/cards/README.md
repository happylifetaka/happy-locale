# オリジナルのサンプルカード5枚

カード編集・OCR・ルビ・アイコン挿入・保護領域を試すための架空のカードです。実際のゲームのルールではありません。

## 素材の出所

名前・英文・幾何学図形によるイラスト・2種類のアイコンは、このサンプル用に作成しました。既存のカード画像、キャラクター、ロゴ、ルール文、外部の画像素材は使用していません。SVGは外部画像・Webフォントを読み込みません。PNG化には環境の標準等幅フォントを使用しています。

このディレクトリはリポジトリの [MIT License](../../LICENSE) に従います。

## 使い方

1. カード編集で空のサンプル用プロジェクトを作成します。
2. `png/` 内の5枚を追加します。各画像は744 × 1039 pxです。
3. OCRで領域候補を作成し、必要な領域を選んで原文を確認します。
4. タイトルや短い見出しに日本語訳を入力して「ルビとして原文の上に表示」を試します。
5. 太陽としずくのアイコンを「アセット編集」で登録し、OCRタブの「元画像のアイコンを指定」で割り当てます。

## デモ用翻訳

### 設定済みプロジェクトで試す

トップページの「カード編集を始める」の下にある「サンプル（デモ）を開く」を押すと、5枚の画像、登録済みアイコン2種、サンプル翻訳プロバイダーを用意した状態で始められます。左側の「まとめて領域検出」→「選択した候補を追加」と進み、左側の「まとめて翻訳」で全カードの候補を一覧確認・反映します。カード名・短い見出し・効果欄の「文字のみ自動補修」、文字色、アイコン位置、バッジの保護領域も候補追加時に設定されます。ルビは使用しません。05の効果欄だけは白文字向け、それ以外は黒文字向けの検出設定です。

デモでは登録済みの領域と原文を候補として表示し、OCR認識処理は実行しません。候補の選択と、追加後の編集・翻訳確認を体験するモードです。通常のOCR精度を試すときは、空の通常プロジェクトへ `png/` の画像を追加してください。

デモを開くたびにブラウザ内へ新しいコピーを作ります。デモでは「プロジェクト保存」は無効です。編集結果は画像やPDFとして書き出せます。OS上のフォルダへ編集データを保存して試す場合は、通常の空プロジェクトへ `png/` の画像を追加してください。デモ設定は [`public/sample-project/project.json`](../../public/sample-project/project.json) に含まれ、カード全体を300 DPIとする印刷設定も用意しています。

### 画像だけで試す場合

「ツール」→「翻訳設定」で「サンプル用（デモ・外部通信なし）」を選んで保存します。領域の原文を確認し、「翻訳」タブの「翻訳候補を取得」から日本語候補を確認・反映できます。選択したプロバイダーはブラウザに保存されます。

複数領域は、右パネル上部の「未翻訳をまとめて取得」でカード内の候補を一括確認できます。原文があり、日本語訳が空の領域だけが対象です。反映したい候補を選んで一括反映でき、Undo一回で戻せます。取得に失敗した領域には理由を表示し、成功した候補だけを反映できます。

デモは左側の「まとめて領域検出」→「選択した候補を追加」→左側の「まとめて翻訳」の順に進めます。「まとめて翻訳」で原画像・原文・訳文を一覧表示します。サンプルの未翻訳行には開いた時点で訳文候補が入り、選択した行を反映できます。CSVも同じ画面で確認・編集できます。デモでは用意済みの領域・原文・アセット指定を使い、個別の「領域候補を表示」は無効です。通常プロジェクトの一括OCRでは実際に画像を認識します。

5枚のタイトル・種別・見出し・効果文に対応しています。改行や通常の空白、大文字小文字の違いは吸収します。アイコンは `sun` / `drop` の名前で登録し、原文中では `[icon:sun]` / `[icon:drop]` にしてください。数字の誤読や未登録の英文はエラーになり、部分的な翻訳は反映しません。カード端のサンプル番号・注意書きは対象外です。

アイコン名は `sun` と `drop` を想定しています。`manifest.json` に正しい英文を保存しています。そこにある `{sun}` / `{drop}` は画像内のアイコン位置を表す確認用記号です。アプリ内では `[icon:sun]` / `[icon:drop]` を使います。

偶数番号のカードには、効果枠の右下に重なる数字バッジがあります。保護領域の練習に使えます。カードによってタイトル位置と効果欄の構成が異なり、単一の配置雛形を前提にしていません。

05「THE QUIET BRIDGE」の効果欄は濃い青緑の背景・白文字です。暗い背景上の白文字について、OCRと背景補修を確認できます。

## ファイル

- `png/`: アプリに追加するカード画像5枚
- `svg/`: 編集可能な元画像5枚
- `contact-sheet.png`: 全5枚の一覧画像（カードとして読み込む必要はありません）
- `contact-sheet-translated.png`: デモの日本語訳・アセットとアプリの描画処理で生成した、翻訳後の全5枚の一覧画像
- `manifest.json`: カード名・種別・正しい英文・確認項目
- `generate.mjs`: SVGと原文データの生成スクリプト。`node samples/cards/generate.mjs` で再生成できます。PNGはSVGを744 × 1039 pxで書き出したものです。

PNGに印刷DPIは指定していません。実寸印刷を試す場合は、アプリで意図したDPIを設定してください。
