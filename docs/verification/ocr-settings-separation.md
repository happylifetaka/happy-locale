# 領域検出の内部設定分離

## 実装範囲

`app/services/ocr/detection-settings.ts` に画像補正の内部設定を分離した。
明るい文字の画素補正と淡色帯の見出し再OCRを個別に無効化でき、色の閾値、帯の形状条件、再OCR回数・採用信頼度を呼び出し単位で渡せる。既定値は従来と同一で、単体・一括検出は引き続き同じ既定値を使う。共有設定は変更不可とし、実行間で設定が漏れない形にした。

これはゲーム別プロファイル機能の完成ではない。候補の行結合、装飾除去、英大文字の見出し判定などはまだ既存処理に残る。設定の外部入力・検証、画面上の切り替え、保存形式の変更は追加していない。画像補正を無効にしても、候補生成側の全補正が無効になるわけではない。

## 非公開プロファイルの今後の扱い（未実装）

- 公開リポジトリには共通エンジンと設定仕様だけを置き、特定ゲームの設定・画像・辞書を同梱しない。
- 専用設定は利用者が管理するローカルJSONとして読み込む方向を推奨。任意のJavaScriptを実行するプラグインにはしない。
- インポート時の型・範囲・バージョン検証は、外部入力を追加するときに実装する。現在の内部設定型をそのままファイル形式として固定しない。
- プロジェクトへの同梱は共有時に専用設定も渡るため、ローカル参照と同梱のどちらにするかは未決定。非公開設定が自動的に書き出される仕様にはしない。
- AIによる作成支援や外部送信は追加していない。
