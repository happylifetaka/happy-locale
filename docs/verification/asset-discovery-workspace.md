# アセット検出の通常画面化

2026-09-21、開発環境で検証。

## 変更

- アイコン候補の収集・確認をモーダルから「アセット検出」画面へ移動。「カード」「アセット編集」と同じ上部ナビゲーションから開く。
- 初回訪問時だけマウントし、タブ往復ではグループ・ページ・チェック・候補編集履歴・比較案を保持する。別カードの候補を選んでも検出画面に留まる。
- 別プロジェクトの世代では作業画面を破棄し、セッション状態を持ち越さない。未適用比較案の明示破棄は画面内へ移動。
- 検出画面からプロジェクト保存が可能。処理中はタブ切替・保存・別プロジェクトを開く操作を無効化。
- 次へ進むとカード画面と既存の領域・原文反映プレビューを開く。反映プレビュー自体は引き続きモーダル。
- 説明文を折りたたみ、候補整理の表示領域を確保。保存形式・検出処理・通信境界は変更しない。
