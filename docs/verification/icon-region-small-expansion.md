# アイコンの小さなはみ出し補正

2026-09-21、開発環境で検証。公開環境・印刷結果の確認ではありません。

## 仕様

- アイコンの所属先が元の枠との交差から一意に決まる場合、各辺のはみ出しが元画像8pxかつアイコン短辺20%以内なら最小拡張案を作る。
- 他領域・同時拡張案との衝突、元から領域外の候補、画像外、手動マスクの描画変化は自動解決しない。未割当・除外・画像不一致の候補で枠を広げない。
- プレビューに拡張量と元枠の破線を表示。通常の反映で枠・アイコン位置・原文を一括確定し、一回のUndoで戻す。
- 訳文・書式と手動関連データの絶対位置を保持。保存形式・外部通信に変更なし。

## 残る制約

小さな枠不足を補正するもので、OCR本文の誤字をなくす機能ではない。実画像ではタグの後ろに余分な文字が残ったため、原文の確認が必要。全37枚の再検証、印刷結果の確認、補正不可候補を直接開く専用導線の追加は今回実施していない。
