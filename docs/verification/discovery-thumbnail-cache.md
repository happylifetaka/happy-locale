# アセット検出：全グループ表示と高画質サムネイル

2026-09-21、開発環境で検証。

## 変更

- グループの8件ごとのページ分割を撤去し、全件スクロール表示に変更。出現候補は24件ごとのまま。
- カード全体の縮小JPEGを拡大する方式をやめ、選択中でないカードも元画像からアイコン範囲を直接切り出す。最大128pxのPNGを64px枠で表示。
- 表示付近だけ要求し、同一画像の処理をまとめて原寸Bitmapを1枚ずつ処理・解放。重複要求とメモリキャッシュを共有し、枠変更・Undo・画面破棄時の座標／資源整合性を維持。
- プロジェクトの `temp/asset-thumbnails/` に自動キャッシュ。元画像内容・範囲・寸法・生成方式のハッシュで識別する。元画像をハッシュ照合した後で利用し、再読込時は元画像デコードを省略できる。
- キャッシュの欠損・破損は再生成。容量・PNGヘッダー・寸法・デコードを検証し、権限不足・書込失敗はプレビューを妨げない。登録アセット・候補・原文・project.jsonはキャッシュ生成で変更しない。

## 制約

旧キャッシュの自動掃除は未実装。`temp/asset-thumbnails/` はアプリを閉じて削除できる。メモリキャッシュ使用中の元ファイル外部編集を常時監視する機能ではない。今回、利用者の37画像全件の再検証、大量グループの性能測定、公開ビルド・公開環境確認は実施していない。
