# 領域追加・アイコン一括反映の検証

実施日: 2026-09-21

## 実装

- 通常プロジェクトの「まとめて領域検出」に、自動追加・アイコン反映を組み込んだ。初期選択を外すと従来の候補確認方式になる。デモは従来方式を維持。
- 候補パネルの「アイコンも反映」で、確認モーダルを挟まず追加できる。操作・保存の説明は折りたたみに移動。
- 既存の枠・訳文・手動指定を保持し、許容される小拡張とタグ付き原文を反映。曖昧な既存領域は変更せず、新規領域のアイコンOCRだけ失敗した場合は検出時の原文・枠で追加する。
- 初回検出の未選択候補も保持する。カード別の通常Undo/Redoに、非表示カードの反映と候補消費・残存候補の保存を接続。
- 要確認箇所はカード一覧にまとめ、対象カードを開ける。実行中の中止では完了分を残し、処理中の遅延結果は適用しない。
