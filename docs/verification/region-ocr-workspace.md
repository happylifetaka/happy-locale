# 領域検出・再OCRとアセット検出の役割分離

2026-09-23、開発環境で検証。

## 変更

- 通常プロジェクトに「領域検出」「まとめて再OCR」の2つの入口を用意し、1枚だけでも対象にできるようにした。「追加・アイコン反映まで実行」「このカードに反映」と、左側の独立した「未反映の内容を確認」を廃止した。
- 中央の「領域・OCR」作業画面で、対象選択→進捗→結果へ切り替える。結果はカードごとの確認事項、対象箇所の画像、現在の原文と修正操作を表示する。全処理カードの一覧は折りたたみ、確認事項を先に見られるようにした。
- 修正先から「OCR結果に戻る」で一覧へ戻れる。結果は同じプロジェクト内の画面往復で保持し、対象カードを再処理すると更新する。別プロジェクト・ページ再読込には持ち越さず、保存形式を変更しない。
- 領域検出は新規領域の追加と初回OCRを担当する。再OCRは確定済み領域をすべて読み直し、アイコンのない領域も処理する。再検出・未確定候補の追加や消費は行わない。両方で割当済みアイコンを使い、手修正した原文・訳文・通常Undo・遅延結果の破棄を維持する。
- アセット検出には「カード全体／確定した領域内」を追加した。領域内では未確定候補を探索範囲に使わず、領域がないカードを全体探索へ切り替えない。抽出結果も領域境界で絞り、小さなはみ出しはOCRと同じ条件で許容する。完全包含でない候補はowner未指定で保存し、従来形式の包含条件を維持する。
- アセット検出から原文への直接反映・個別OCR比較の入口を外し、領域検出または再OCRの作業画面へ案内する。
