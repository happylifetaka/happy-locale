# 初回翻訳設定の検証

実施日: 2026-09-22

## 変更

- 通常のカード編集開始時、未設定の場合だけ既存の翻訳設定モーダルを開く。
- 翻訳プロバイダーの上に初回案内を表示する。
- 手動を含む明示的な保存を完了扱いにする。初期値の読込・キャンセル・デモ開始では完了扱いにしない。
- 設定は既存のlocalStorageキー・形式を維持し、保存済みの通常用設定を引き継ぐ。旧sample設定は接続先を引き継ぎつつ、通常用の方式選択を案内する。
- プロジェクト未選択でもツールから翻訳設定を開ける。

## 確認

- 対象単体・コンポーネントテスト30件成功。未保存・不正値・保存済み各方式・旧sample・保存不可・キャンセル・再入場・プロジェクト変更を確認。
- 全体の単体・コンポーネントテスト1,526件成功。
- アプリ・テストの型検査、変更したTypeScript／VueのESLint、`git diff --check`成功。
- Playwright 4件成功。ホームからの初回開始、手動保存後の再入場・再読込、通常設定の案内非表示、キャンセル後の再案内、デモ除外、既存の翻訳一覧を確認。
- 初回モーダルのスクリーンショットで、プロバイダーの上の案内とボタン配置を目視確認。
