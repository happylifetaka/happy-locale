# 一括作業のカラム統一と再検出

確認日: 2026-09-25

## 実装

- 左のカード一覧を残し、中央と右のカラムを領域検出・再OCR・翻訳確認の作業領域として使用する。
- 対象チェックとカードの閲覧を分離し、操作別の対象選択と候補・結果を同一プロジェクト内で保持する。別プロジェクトへ持ち越さない。
- 既存領域があるカードも再検出できる。検出は未選択の候補を追加し、明示採用まで領域を作らない。保存済み候補と既存領域は保持する。
- 既存領域・候補との重複追加を防止する。領域採用のUndoでは、その採用前の候補に戻る。
- 翻訳候補は反映まで既存訳を変更しない。編集画面との往復では下書きを保持し、原文等が変わった行の古い候補は破棄する。
- 狭い画面ではカード一覧と作業領域を縦に配置し、翻訳の反映ボタンまでスクロールで到達できる。
- デモも同じ作業画面を使用し、同梱候補・領域設定を使う。実OCRは呼ばない。
