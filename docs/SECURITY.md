# セキュリティポリシー

## 対象

現在は安定版リリースを公開していないため、原則としてデフォルトブランチの最新コードを調査・修正対象とします。過去のコミットや未サポートのブラウザへ個別の修正提供は保証していません。

## 脆弱性の報告

脆弱性の詳細を公開Issueへ投稿しないでください。

GitHubリポジトリのSecurityタブでPrivate vulnerability reportingを利用できる場合は、そこから非公開で報告してください。利用できない場合は、機密情報や再現コードを含めずに「非公開のセキュリティ連絡手段が必要」とだけIssueで知らせてください。

報告には、可能な範囲で次を含めてください。

- 影響する機能とブラウザ
- 再現条件
- 想定される影響
- 外部送信、ローカルファイル、保存データに関係するか
- 公開可能になるまで避けるべき情報

受領後、再現可否と対応方針を確認します。個人開発のため返信期限や修正期限は保証できませんが、確認前に詳細を公開しないようお願いします。

## 特に報告してほしい問題

- ユーザー操作や明示なしに画像、PDF、原文、フォント、プロジェクトデータが外部送信される
- 選択したプロジェクトフォルダの外側を読み書きできる
- 悪意ある`project.json`やCSVによって任意コード実行、意図しない外部通信、別ファイルの上書きが起きる
- 保存失敗によって既存プロジェクトが回復不能になる
- Translation Endpointへ画面説明と異なるデータが送信される

通常の不具合、背景補修品質、OCR精度、未対応ブラウザの問題は公開Issueで報告できます。
