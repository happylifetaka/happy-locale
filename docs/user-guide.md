# HappyLocale 利用ガイド

このガイドでは、カード画像、PDF、翻訳CSV、インラインアセット、フォントを扱う詳しい操作を説明します。概要、対応環境、セットアップは[`README.md`](../README.md)を参照してください。

## カード画像の編集

### 配置雛形

プロジェクトを一度保存すると、「領域一覧」の下にある「配置雛形」から配置を再利用できます。

1. 見本の画像で領域・文字設定・保護領域を整え、「このカードの領域を雛形にする」を押します。
2. 任意の名前を入力し、保存する領域を選んで登録します。役割は未設定でも構いません。
3. 別の画像で「配置雛形から領域を追加」を開き、青い領域枠と赤い保護領域を元画像に重ねて確認します。
4. 必要な領域だけ選び、横移動・縦移動・倍率を調整して追加します。画像からはみ出す場合は追加できません。
5. 原文と訳文を入力し、必要なら個々の領域を微調整してプロジェクトを保存します。

原文と訳文は雛形へ複製しません。既存領域と重なる場合も既存の編集は保持したまま追加するため、重複した領域が不要なら一覧から削除してください。追加全体を1回のUndoで戻せます。雛形の登録自体はプロジェクト共通設定で、領域のUndo対象には含みません。

### 領域の役割と基本操作

複数の欄をまとめて認識した領域は、一覧の「分割…」または選択中の「この領域を分割…」で2つに分けられます。上下・左右と分割位置を指定し、分割後の原文・訳文を確認します。初期状態では文章を最初の領域にすべて保持するため、必要な文章を2つ目へ移してから確定してください。繰り返して3つ以上にも分けられます。保護領域は分割線で切り分け、手動マスクも位置を引き継ぎます。1回のUndoで分割前の状態へ戻せます。

最初の領域のCSV用IDは保持し、2つ目には新しいIDを付けます。分割前のCSVをそのまま使うと文章の区切りが合わないことがあるので、分割後にCSVを出し直してください。訳文がある場合も分割後は下書きへ戻り、文字装飾と配置の再確認が必要です。

領域の「役割」は任意の分類名です。「領域一覧」または選択中の領域の「領域の役割」へ自由に入力できます。同じプロジェクトで使った名前は入力候補に表示されます。空欄は未分類として扱い、役割がなくても通常どおり編集できます。一覧の役割フィルターで絞り込めます。役割を付けても文字の配置や背景処理は変わりません。

ホームの「カード編集を始める」から移動します。作業中はツールバー左端の作業切替メニューからPDF翻訳へ移動でき、Hアイコンまたはメニューの「ホーム」でホームへ戻れます。

1. 「プロジェクトを開く／作成」からフォルダを選びます。保存済みの作業では`project.json`があるフォルダ、新規作業では空のフォルダを選びます。
2. 新規作業では「カード画像を開く」からPNGまたはJPEGを選びます。
3. 英語テキスト部分をドラッグして矩形領域を作ります。
4. 背景処理を選びます。通常は「文字のみ自動補修」、検出しにくい文字は「手動マスク補修」、均一な背景は「単色塗りつぶし」を使います。見出しや空欄へ文字だけを重ねる場合は「塗りつぶさない（文字のみ）」を選びます。
5. 右側の「領域一覧」から編集対象を選び、「領域」「OCR」「翻訳」を切り替えて設定します。入力欄からフォーカスを外すと変更が確定します。
6. 必要に応じて上部の「ツール」から翻訳CSVを保存し、`translation`列を編集してから読み込みます。
7. 「プロジェクト保存」で画像と編集データを選択済みフォルダへ保存します。
8. カード一覧の操作メニューからカード名の変更、並べ替え、合成画像のPNGまたはJPEG保存を実行できます。

カード画像とアセット元画像の表示倍率は25%から200%まで変更できます。表示倍率は書き出し解像度に影響しません。

上部ツールバーには、作業切替、カード／アセット切替、保存、Undo／Redoだけを常時表示します。プロジェクトの変更、CSV、用語集、翻訳設定は「ツール」にまとめています。右パネルは「領域一覧」「領域」「OCR」「翻訳」「印刷範囲」の5タブです。領域一覧では鉛筆ボタンから表示名を変更でき、Enterまたはフォーカス移動で確定、Escapeでキャンセルできます。領域を削除する場合は×を押し、確認画面で確定します。

### 背景処理

- 文字のみ自動補修: 文字色の候補を検出し、周囲の背景から補間します。自動判定、白文字、黒文字のプリセットと検出強度を選べます。
- 手動マスク補修: ブラシで塗った部分だけを補修します。追加、消しゴム、1ストローク単位のUndo／Redoを利用できます。
- 単色塗りつぶし: 領域全体を指定色で塗ります。
- 塗りつぶさない: 元画像を変更せず、訳文とインラインアセットだけを重ねます。

保護領域を指定すると、自動補修と手動マスク補修の対象からアイコンなどを除外できます。現在の保護領域は矩形のみです。

## 複数カードプロジェクト

カード一覧の「＋」では複数ファイルを選択できます。「フォルダから追加」は選択フォルダ直下のPNG／JPEGだけをファイル名順で追加し、サブフォルダには入りません。

カードが2枚以上ある場合は「一括保存」から全カードをPNGまたはJPEGで順次書き出せます。ファイル名には一覧順の3桁連番が付き、削除予定カードは除外されます。

ツールバーには「未保存の変更あり」または「保存済み」を表示します。領域だけでなく、カード順、アセット、フォント、OCR辞書、削除予定も判定対象です。

カード一覧には領域数、原文入力済み数、訳文入力済み数を表示します。プロジェクト内検索では表示名、CSV ID、原文、訳文、翻訳ステータスを使って全カードを検索できます。

カードを切り替えるとUndo／Redo履歴もカード別に退避され、同じカードへ戻ると再利用できます。履歴はプロジェクトへ保存されず、ブラウザの現在セッションを終了すると破棄されます。

## 印刷範囲とA4面付け

既存カードへ貼る和訳シールを作る場合は、カードごとに必要な部分だけを印刷範囲として指定します。

1. カードを開き、右側の「印刷範囲」タブで画像上の始点と終点を順にクリックするか、ドラッグします。作成後は移動と四隅のリサイズに加え、画像上のx・y座標と幅・高さ（px）を数値で調整できます。
2. 同じ位置を使うカードが複数ある場合は「未設定カードへ一括適用」を使います。画像寸法が異なるカードには位置と大きさの比率を保って適用されるため、各カードで最終確認してください。
3. PNG／JPEGにDPIメタデータがあれば自動で使用します。DPI未確認と表示された場合は、その画像を作成・スキャンした際のDPIを入力します。DPIを推測した状態ではPDFを出力しません。
4. カード一覧上部の「PDF(A4)作成」を押します。既定ではA4縦へ1行最大3枚を指定したカード間隔で詰めて並べます。3枚そろった行は中央配置し、枚数が列数に満たない最終行は左余白から配置します。1行がページをまたぐ場合は行全体を次ページへ送ります。
5. 必要に応じて列数、余白、カード間隔、切り取り用トンボを調整し、「A4 PDFを保存」を押します。
6. PDFビューアーやプリンターでは「実際のサイズ」または「100%」を選び、「用紙に合わせる」を無効にして印刷します。

PDFには背景補修と訳文を反映した印刷範囲が元画像DPIに基づく実寸で配置されます。指定範囲がA4の印刷可能領域へ収まらない場合、DPIまたは範囲が未設定の場合は、理由を表示して出力を止めます。プリンター固有の印刷不能領域は機種によって異なるため、初回は定規で仕上がり寸法を確認してください。

横幅が収まらない場合は、シール幅合計、間隔合計、左右余白合計、超過量、設定可能な片側余白の上限を表示します。シールを自動縮小することはありません。

## 翻訳CSV

プロジェクト全体のCSVは次の形式です。`card_name`と`display_name`は確認用で、読み込み時は`card_id + region_id`を照合キーとして`translation`だけを更新します。

```csv
card_id,card_name,region_id,display_name (readonly),original,translation
4d8...,card001.png,effect_1,効果,Draw 2 cards.,カードを2枚引く。
```

従来の`region_id,original,translation`形式も読み込めます。この形式では現在選択中のカードだけを更新します。

CSVを読み込むと、適用件数、未一致、重複、現在の原文との差異を表示します。確認後に反映またはキャンセルできます。重複行はCSV内で後にある訳文を採用します。削除予定カードは出力・読み込み対象に含みません。

CSVへ書き出す値が`=`、`+`、`-`、`@`で始まる場合は、表計算ソフトによる数式実行を防ぐ接頭辞を自動で付けます。HappyLocaleへ読み戻す際は接頭辞を取り除くため、原文と訳文は変化しません。

各領域の翻訳ステータスは「未翻訳」「下書き」「確認済み」です。訳文の入力、CSV反映、α機能による翻訳で「下書き」へ戻り、空にすると「未翻訳」になります。「確認済み」は内容確認後に手動で指定します。

上部の「ツール」から開く「用語集」では、プロジェクトで統一したい原文、訳語、任意のメモを追加・編集・削除・検索できます。同じ原文は大文字・小文字を区別せず1件だけ登録できます。「翻訳」タブで領域を編集すると、元テキストに含まれる登録語が「用語集の候補」に表示され、「訳語を挿入」で日本語訳のカーソル位置または選択範囲へ反映できます。用語集は`project.json`へ保存され、外部へ送信されません。

## Translation Endpoint（α）

この機能はAPIクライアントの単体テストと、ローカル翻訳モックとのブラウザ結合動作を確認済みです。

Cloudflare Pages版ではセキュリティ上の理由からTranslation Endpointを無効化しています。翻訳設定、接続確認、翻訳ボタンは表示されません。この機能を使用する場合はHappyLocaleをローカルで起動してください。

「ツール」の「翻訳設定（α）」でTranslation Endpointを選ぶと、「翻訳」タブの元テキスト欄の下に翻訳ボタンが表示されます。ボタンを押すと送信先、原文、言語を確認する画面を表示し、確認後に原文と言語だけをユーザー指定のHTTP(S) Endpointへ送信します。返された結果も現在の訳文と並べて確認し、「提案訳を反映」を押すまで領域へ保存しません。外部URLを指定した場合、原文はその外部サービスへ送信されます。設定はブラウザの`localStorage`に保存され、`project.json`には含まれません。URLにユーザー名、パスワード、query、fragmentを含めることはできません。接続確認と翻訳ではHTTPリダイレクトを拒否します。

既定Endpointは`http://localhost:4578`です。想定しているAPI契約は次のとおりです。

```http
POST /translate
Content-Type: application/json

{"text":"Draw two cards.","source":"EN","target":"JA"}
```

成功時はHTTP 2xxと`{"translatedText":"カードを2枚引く。"}`を返します。

```http
GET /health
```

成功時はHTTP 2xxと`{"status":"ok","provider":"deepl"}`を返します。`provider`は省略できます。ブラウザから接続できるよう、サーバー側でHappyLocaleのOriginに対するCORS設定が必要です。

HappyLocaleは翻訳サービスのAPIキーを保持・送信しません。必要な認証情報はEndpoint側で管理してください。

## インラインアセット

1. 「アセット編集」へ切り替えます。カード編集状態とUndo履歴は保持されます。
2. 「アセット元画像を開く」から採取に使うPNG／JPEGを選びます。この画像はカード画像とは独立しています。
3. 「新しいアセットを切り出す」を押し、アイコンを矩形で囲みます。
4. 重複しない名前を付け、背景透明化の許容色差と境界ぼかしを調整します。必要なら背景色を指定し、追加・消しゴムブラシで補正します。
5. 確定後は表示倍率、上下位置、文字との左右余白を調整できます。
6. カード編集の「翻訳」タブから訳文へ挿入します。

`カードを引き、[icon:coin]を得る。`のように保存され、Canvasと画像出力ではトークン位置へアセットが描画されます。同じ名前のトークンが複数ある場合は、出現箇所ごとの倍率、上下位置、左右余白も指定できます。

名前変更時は全カードの既存トークンも更新します。未登録のトークンは削除せず文字列のまま表示し、警告します。出現箇所ごとの設定はアセット名と同名トークン内での出現順を基準に追従します。

アセット元画像全体は保存せず、切り出した透過PNGだけを`assets/`へ保存します。透明化設定とブラシ履歴は保存せず、確定したPNGへ結果を焼き込みます。確定後にやり直す場合は元画像を再選択し、「切り出し直し」を使います。

アセットの作成、設定、削除はカード編集のUndo／Redo対象外です。

## フォント

「フォントファイルを読込」から、利用可能なTTF、OTF、WOFF、WOFF2を選択できます。ChromeではLocal Font Access APIを使ってインストール済みフォントも選択できます。

領域全体のフォント、フォントサイズ、横位置（左・中央・右）、縦位置（上・中央・下）を指定できます。「領域内に収まるよう自動調整」は入力したフォントサイズを上限として必要な場合だけ縮小し、無効にすると指定サイズを維持して領域外をクリップします。新しい領域とこの設定を持たない旧プロジェクトでは自動調整が有効です。新しい領域と縦位置設定を持たない旧プロジェクトは、縦方向の中央に配置されます。訳文の選択範囲へ部分的な文字色・フォントも指定できます。部分指定と配置設定は`project.json`へ保存されますが、翻訳CSVには含まれません。

フォント本体は外部へ送信せず、ブラウザのIndexedDBへ保存します。`project.json`にはフォント本体を埋め込まず、参照情報だけを保存します。サイトデータを削除した場合や別のブラウザ・PCで開いた場合は、同じフォントを再選択してください。

フォントのウェイト選択、太字、ルビは未実装です。

## OCR

選択領域または画像全体の候補検出に、ブラウザ内で動作するTesseract.js英語モデルを使用します。Worker、WASM、学習データはHappyLocaleから配信し、画像や切り出し領域をOCRサービスへ送信しません。

画像全体の「領域を自動検出」は試験機能です。結果を直接確定せず、候補の選択・調整後に通常領域へ追加します。他のOCRエンジンは未実装です。

領域未作成のカードが2枚以上あるプロジェクトでは、カード一覧の「まとめて領域検出」でローカルOCRを順次実行できます。処理中に保持する原寸画像は1枚だけです。カード一覧に候補件数、候補なし、失敗を表示し、確認待ちカードを開くとOCRタブで候補を調整できます。「選択した候補を追加」または「候補を破棄」すると次の確認待ちカードへ進みます。中止操作は処理中のカードが完了してから反映され、未確定候補はプロジェクトへ保存されません。

## PDF翻訳

PDF翻訳はカードプロジェクトとは独立した画面です。ホームの「PDF翻訳を始める」から移動します。作業中はツールバー左端の作業切替メニューからカード編集またはホームへ移動できます。「新しいPDFを開く」でローカルPDFを選び、ページごとのテキストレイヤーを検査して文字PDF、画像PDF、混在PDFを判定します。

途中の作業は「作業を保存」から`.happy-locale-pdf.json`へ保存できます。解析結果、翻訳、CSV対象外の項目、保護領域、背景と文字色の設定が含まれますが、元PDF自体は含まれません。再開するときは「保存した作業を開く」でJSONを選び、案内に従って元PDFを選択します。SHA-256指紋が一致しないPDFでは復元しません。

PDFの解析中と翻訳PDFの書き出し中はページ単位の進捗を表示します。「キャンセル」で処理を中断でき、翻訳PDFは完了するまでダウンロードされません。

100ページを超えるPDFでは、ページの解析を始める前にページ数と負荷の警告を表示します。「読み込みを続ける」を選べば、そのまま処理できます。メモリ確保の失敗をブラウザから捕捉できた場合は、他のタブを閉じるかPDFを分割して再試行する案内を表示します。ただし、OSやブラウザがタブ自体を強制終了した場合は、アプリからエラーを表示できません。

パスワード付きPDFは読み込めません。パスワードを解除したコピーを用意してください。フォーム、リンク、注釈を検出した場合は件数と注意を表示します。これらは編集せず元PDFに保持しますが、PDFビューアーごとの差もあるため、書き出したPDFで入力値、リンク先、注釈表示を確認してください。

1. 「PDFを開く」でローカルPDFを選びます。
2. 「文字CSVを保存」で文字ページの原文を書き出します。
3. CSVの`translation`列を編集して読み込みます。
4. ページプレビューで背景補間と訳文を確認します。抽出原文に誤りがあれば文字枠を選び、インスペクターで修正します。「前へ」「次へ」で同一ページ内のCSV出力順も変更できます。連続する文字項目は「次の項目と結合」でまとめられ、原文を複数行にして「改行で分割」すると行ごとの項目に分けられます。
5. CSVへ出さない文字枠を選び、「CSV対象から除外」で対象外にします。
6. 必要なら保護領域を追加します。
7. 日本語訳を検索・選択可能にする場合は、「訳文のPDF形式」で日本語対応のTTF / OTFを選びます。
8. 「翻訳PDFを保存」で元PDFとは別のファイルを保存します。

画像ページでは「範囲を選んでOCR」を有効にし、文字のある矩形をドラッグします。その範囲だけをブラウザ内の英語OCRへ渡し、結果を新しいPDF文字項目としてCSV対象へ追加します。選択外の図中文字、数字、ページ番号はOCRしません。CSVから訳文を読み込むと、通常の抽出文字と同様に選択範囲だけを背景補修して訳文を重ねます。

元PDFをページ画像へ変換せず、対象文字範囲だけを背景パッチで覆います。TTF / OTFを選ぶと、使用する文字だけをフォントからPDFへ埋め込み、日本語訳を検索・選択可能なテキストとして重ねます。フォントを選ばない場合はCanvasで描いた画像文字を重ねます。どちらの場合も、対象外のテキスト、ベクター図形、画像、ページ寸法は元PDFのままです。

PDF用に選んだフォント本体は外部へ送信せず、PDF作業JSONにも含めません。作業を開き直した後は再選択してください。訳文に必要な文字を収録し、PDFへの埋め込みが許可されたフォントを使用してください。

原文の修正・結合・分割を行うと、変更対象の既存翻訳はクリアされます。結合元のどちらかがCSV対象外なら結合後も対象外になり、対象外の項目を分割した場合はすべての分割項目が対象外になります。

現在の制約:

- 画像ページのOCRは利用者が選択した矩形ごとに行う
- 画像ページをカード編集へ自動転送しない
- 元文字の描画命令は削除せず、背景パッチで視覚的に隠す
- 埋め込みフォントを選ばない場合、重ねた日本語訳は画像なので検索・選択できない
- 複雑な図柄、文字自体の任意角度回転、縦書き、特殊な段組みでは見た目が一致しない場合がある
- PDF作業JSONにフォント本体は保存しない
- フォーム、注釈、リンク自体の編集には対応しない

詳細な計画は[`PDF_TRANSLATION_ROADMAP.md`](PDF_TRANSLATION_ROADMAP.md)を参照してください。

## プロジェクトフォルダ

Chrome系ブラウザのFile System Access APIを使い、ユーザーが明示的に選択したフォルダだけを読み書きします。

```text
MyProject/
  project.json
  project.backup.json
  images/
    <カードID>.png
  assets/
    <アセットID>.png
  thumbnails/
    <カードID>.jpg
```

- `project.json`: 相対パス、画像寸法、翻訳領域、参照情報など
- `project.backup.json`: 2回目以降の保存前の編集データ
- `images/`: 読み込んだ元画像のコピー
- `assets/`: 切り出した再利用用PNG
- `thumbnails/`: カード一覧用の最大144×180px JPEGキャッシュ

画像バイナリをJSONやUndo履歴へ埋め込まず、表示中の原寸カード画像だけを読み込みます。カード一覧では、表示範囲とその少し先にあるサムネイルだけを最大2件並列で遅延読み込みします。`thumbnails/`は削除可能なキャッシュです。旧プロジェクト、欠損、破損時は元画像からバックグラウンドで再生成されます。

`project.json`はversion 2です。version 0、version省略形式、version 1は不足する印刷設定を補ってversion 2へ読み替え、未知の将来versionは対応外として拒否します。フォルダハンドルのセッションをまたぐ保存と権限再取得は未実装です。

## 読み込み上限

ブラウザタブのメモリ枯渇や長時間停止を避けるため、次の上限を設けています。上限を超えたファイルは内容のデコードまたは解析前に拒否し、別のファイルを選び直せます。画像とPDFは容量確認後、展開後の寸法も確認します。

| 種別 | 上限 |
| --- | ---: |
| PNG／JPEG | 50 MiB、一辺32,768px、合計100メガピクセル |
| PDF | 100 MiB、ページ数の明示上限なし、一辺14,400ポイント |
| 翻訳CSV／`project.json` | 20 MiB |
| CSV行数 | 100,000行 |
| プロジェクトのカード／アセット | 各10,000件 |
| カードごとの文字領域 | 10,000件 |
| `project.json`内の文字列 | 1,000,000文字 |
| フォント | 20 MiB |

上限値は一般的なカード画像とルールPDFを十分扱える余裕を残しつつ、ブラウザ上で極端なメモリ確保が始まる前に停止する初期値です。

## 診断ログ

画像やプロジェクトを開けない場合は、上部の「ツール」から「診断ログ」を開いて操作を再試行してください。ログには処理段階、ファイル形式、サイズ、ファイル名・フォルダ名などが含まれる場合がありますが、画像内容やローカルの絶対パスは記録しません。同じ内容をChrome DevToolsのConsoleにも`[HappyLocale]`付きで出力します。
