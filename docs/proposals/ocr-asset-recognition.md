# 改善案: OCRとアセット認識・登録の統合

作成日: 2026-09-17

状態: 提案。以下の追加機能は未実装。

## 解決したい課題

文章中のアイコンをOCRが文字として認識し、原文に誤字が混ざる。利用者はアセット登録、原文上の範囲指定、OCR結果の修正を別々に行う必要がある。

OCRの確認中にアセット候補を選択・新規登録し、原文の正しい位置へアイコンタグを入れられるようにする。

例:

```text
元画像: Gain 2 ☀.
誤認識: Gain 2 O.
確定する原文: Gain 2 [icon:sun].
翻訳例: 2 [icon:sun]を得る。
```

## 現在の実装

- [SourceIconsDialog.vue](../../app/components/SourceIconsDialog.vue): 登録済みアセットを選び、元画像上でアイコン範囲を手動指定できる。新規登録は別画面で行う。
- [image.ts](../../app/services/ocr/image.ts): 指定範囲をOCR用画像から除外できる。
- [tesseract.ts](../../app/services/ocr/tesseract.ts): OCR結果に単語座標と信頼度を含める。
- [source-icons.ts](../../app/utils/source-icons.ts): 単語とアイコンの位置から、原文へ `[icon:名前]` を差し込む。

この基盤を拡張し、画像照合による候補提示と、その場での登録を追加する。

## 操作フロー

1. 翻訳領域のOCRを開始し、文章とアイコン候補を表示する。
2. 元画像の候補枠を選ぶと、切り抜き画像と登録済みアセットの一致候補を表示する。
3. 各候補で「既存アセットを使う」「新規登録」「文字として扱う」を選ぶ。
4. 新規登録では、範囲、名前、背景透明化を確認して登録する。OCRの作業位置へ戻る。
5. 見落としたアイコンは、ドラッグで候補を追加する。候補枠も調整できる。
6. 確定したアイコン範囲を除外して対象領域を再OCRし、タグ入りの原文候補を表示する。
7. 利用者が原文を確認して適用し、翻訳候補の生成へ進む。

最初は一致候補が一つでも確認を挟む。高確度の一致を自動適用する機能は、誤検出率を評価してから追加する。

## 実装方針

### 既存アセットとの照合を先行する

ブラウザ内で切り抜き画像と登録済みアセットの画像照合を行う。サイズ差、透明部分、背景色の違いを考慮する。候補のスコアと次点との差を使い、似たアイコンが複数ある場合は選択を求める。スコアをそのまま正解確率として表示しない。

OCRが高い信頼度でアイコンを文字と誤認識する場合もあるため、低信頼度の単語だけを照合対象にしない。OCR前の画像も照合に使い、アイコンの周囲の文字・数字を除外範囲へ巻き込まないようにする。

### 未登録アイコンの検出は段階的に追加する

初期段階は手動範囲指定から新規登録できる導線を作る。その後、文字行内の図形やOCR結果との不整合を使った候補抽出を検証する。装飾・句読点・文字を完全に分類できる前提にはしない。

### 仮候補と確定情報を分ける

仮候補には画像上の範囲、一致するアセットID群、照合スコア、利用者の選択状態を保持する。確定時は既存の `sourceIcons` とアセット参照へ変換する。仮候補を永続化するかは初期実装では保留し、既存プロジェクトの読込互換性を維持する。

領域内座標・画像座標・OCR拡大後の座標を明示的に変換する。処理中のカード切替、領域変更、アセット変更で古い結果が適用されないようにする。

### 誤字の置換ではなく、画像を基準に原文を再構成する

誤認識された文字列を検索置換すると、本物の文字まで消す恐れがある。確定範囲を除外した再OCRと単語座標を使う。単語位置が取得できない場合は自動適用せず、手動確認へ戻す。

アセット作成と原文への適用の取り消し範囲を明確にする。他領域で使用中のアセットを、原文のUndoに伴って削除しない。

## 段階的な実装

1. OCR確認画面からの範囲指定・既存アセット選択・新規登録を統合する。
2. 登録済みアセットの画像照合と、複数候補の選択を追加する。
3. 未登録アイコンの候補抽出を検証する。
4. 同じアセットを含む複数カードへ候補提示を展開する。

## 完了条件と検証

- [ ] OCRの作業を中断せず、新規アセットを登録して原文へタグを反映できる。
- [ ] 一致候補が複数ある場合、既存候補の選択と新規登録の両方ができる。
- [ ] 行頭・行中・行末、同一アイコンの繰り返し、連続する複数アイコンを扱える。
- [ ] アイコンに隣接する数字・句読点が失われず、誤認識文字とタグが二重に残らない。
- [ ] 見落としや誤検出を手動修正でき、取消・再試行でも参照が壊れない。
- [ ] 保存・再読込後もアセット参照と原文タグが維持される。
- [ ] 代表カードで手動指定回数、原文の修正箇所数、処理時間を現行方式と比較する。

画像の大小、背景色、類似アイコン、アイコンなしのカードを含めて評価する。認識精度の採用基準は、この比較で決める。
