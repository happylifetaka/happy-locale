# 改善案: 文章領域の自動選択と微調整

作成日: 2026-09-17

状態: 提案。以下の追加機能は未実装。

## 解決したい課題

人には一つの文章と分かる範囲が、OCRでは複数領域に分かれたり、別の文章と結合されたりする。自動検出の精度と、外れた場合の修正操作の両方を改善する。

目標は、カード名・種別・効果文・注釈などを適切に分け、利用者が少ない操作で確定できること。

## 現在の実装

- [candidates.ts](../../app/services/ocr/candidates.ts): 行間と横方向の重なりを使ってOCR行を結合する。信頼度、英字数、記号の比率、行の高さで候補を絞る。
- 同ファイルの分割処理は、候補に含まれる行数の中央を境に上下へ分割する。
- [useRegionCandidates.ts](../../app/composables/useRegionCandidates.ts) と [RegionCandidatePanel.vue](../../app/components/RegionCandidatePanel.vue): 候補の選択・移動・サイズ調整・分割・変更の取り消しを扱う。
- [LayoutTemplateDialog.vue](../../app/components/LayoutTemplateDialog.vue): 既存の領域配置をテンプレートとして保存・配置する仕組みがある。

テンプレートやサイズ調整を新設するのではなく、既存機能を活用し、候補のまとめ方と修正導線を拡張する。

## 操作フロー

1. 自動検出した候補を画像上に表示する。
2. 一つの文章が分かれている場合は、複数候補を選び「結合」する。
3. 別の文章がまとまっている場合は、行間を選んで「ここで分割」する。
4. 辺や角をドラッグして余白を整える。必要に応じて認識済み文字の外接範囲へ合わせる。
5. 修正した候補の原文と読み順を確認し、翻訳領域として確定する。
6. 同じレイアウトのカードには既存テンプレートを利用し、配置確認後にOCRする。

「追加対象のチェック」と「結合操作の対象選択」を区別し、誤って全候補を結合しないUIにする。

## 実装方針

### 自動結合の判断材料を増やす

現状の行間・横方向の重なりに加え、行の高さの比率、左端の揃い、段落間の余白を評価する。見出しと本文、左右の段組み、箇条書きを別々のケースとして検証する。

短い見出しや数字だけの行がフィルタで落ちることも確認する。閾値を一律に緩めるだけでは装飾の誤検出が増えるため、本文候補に隣接する短い行を再評価する方式を検討する。

### 任意の行間で分割する

初期実装では、認識済みの行と行の間を分割位置として選べるようにする。分割後は各行群から範囲と本文を再計算する。文字行の途中を切る操作は別途手動の領域作成で扱い、単語を機械的に二分しない。

### 複数候補を結合する

選択した候補の行を集め、重複を除き、読み順を再構成して一つの候補にする。離れた候補や段組みを選んだ場合も、適用前に原文と範囲を確認できるようにする。

結合・分割は一操作単位で取り消せるようにし、一括OCR側に保持する候補にも同じ変更を反映する。

### 枠の調整と本文の更新を一致させる

サイズを変えて新しい文字を範囲に含めた場合、枠だけ広がって原文が古いままにならないよう、再OCRが必要な状態を表示する。認識済みの行だけで再構成できる操作と、画像の再認識が必要な操作を分ける。

候補の結合・分割はまず確定前の候補を対象にする。確定済み領域には訳文、書式、背景処理、原文アイコンなどがあるため、それらの統合・座標変換まで暗黙に行わない。

### テンプレートによる繰り返し作業の削減

既存テンプレートへの保存・配置を候補確認の流れから利用しやすくする。異なる画像サイズでは配置プレビューを必須とし、はみ出しや不適切な拡大率を確認する。複数カードへの一括適用は、個別適用の検証後に追加する。

## 段階的な実装

1. 候補の複数選択・結合と、任意の行間での分割を追加する。
2. 枠の調整後の原文更新・再OCRの導線を整える。
3. 代表画像で行の結合判定と候補フィルタを改善する。
4. 既存テンプレートの導線を整理し、複数カードへの適用を検討する。

## 完了条件と検証

- [ ] 分かれた文章を、原文の欠落・重複なく一つの候補へ結合できる。
- [ ] 好きな行間で分割でき、それぞれの本文と範囲が一致する。
- [ ] 取り消し後に本文・範囲・選択状態が復元される。
- [ ] 枠の変更によってOCR結果が古くなった場合に、確認・再認識できる。
- [ ] 見出し、複数段落、箇条書き、短文、数字、左右の段組みで結果を比較する。
- [ ] アセットが入る行でも、文章の分断や別段落との誤結合が増えない。
- [ ] テンプレート適用時に既存領域を意図せず上書きしない。

現行方式と比較して、一枚あたりの結合・分割・枠調整の回数と、確定までの時間を記録する。自動検出だけの正解率に加えて、手動修正を含めた作業量で判断する。
