# HappyLocale 手動回帰確認

## 翻訳・ダイアログ・印刷のデータ保持

- 一括翻訳確認で2領域の訳を編集し、片方のチェックを外して反映する。画面が開いたままで、未選択の訳が保持され、未反映1件と表示されること。残りを選択して反映すると閉じ、再度開くと両方の訳が保持されていること。一部反映後に「閉じる」を押した場合は、残りの変更の破棄確認が出ること。
- PDFで2行の訳を取り込んだ後、1行だけの修正CSVを取り込む。対象の訳だけ更新され、もう1行は変わらないこと。別PDF名のCSV・一致するIDがないCSVでも既存訳が消えないこと。対象行の訳が空欄のCSVでは、その行だけ空欄にできること。
- カードを編集してUndo履歴を作り、一括翻訳確認・元アイコン指定などのダイアログを開く。ダイアログ内のボタンにフォーカスしてCmd/Ctrl+Z、Cmd/Ctrl+Shift+Z、Ctrl+Yを押しても背後のカードが変化しないこと。閉じた後は通常のUndo/Redoが使えること。
- 多数のカードでA4印刷を開き、プレビュー生成中に「カード編集へ戻る」を押す。再度開いて正常に生成・出力できること。途中終了後のURL解放と残りカードの生成停止は `tests/composables/usePrintPreviews.test.ts` の遅延処理テストでも確認する。

自動テストで扱いにくいFile System Access API、Canvas操作、ブラウザフォントを中心に、リリース前にGoogle Chromeで確認します。テストには自作のPNGまたはJPEGを2枚以上使用します。

## プロジェクトとカード

- 新規作成→初回保存→訳文編集で未保存表示になり、再保存して開き直すと最新の訳文が残る。初回保存前後で選択領域とUndo／Redo履歴も維持される
- 保存中は二重保存・カード切り替え・編集操作ができず、処理完了または失敗後に操作へ戻れる
- 未保存アセットを登録してからカードを追加し、追加完了後にフォルダを開き直してアセット画像が復元される
- Aを開いた状態で破損アセットを含むBを開くと、エラー後もAの画像・領域・フォルダ・未保存状態を維持し、Aの編集と保存を続けられる
- 未保存のカード編集・PDF作業から作業切替、ホームのロゴ、ブラウザの戻る操作を行うと離脱確認モーダルが表示される。「編集に戻る」とEscapeでは画面・入力・作業切替の選択値を維持し、「保存せずに離れる」では移動する
- 離脱確認モーダル内でTabキーのフォーカスが循環する。保存済みの作業では確認なしで移動し、未保存時のタブ終了・再読み込みではブラウザ標準の確認が表示される
- PDFのCSV読込、OCR追加、除外・保護領域・原文・描画設定変更後は離脱確認が出る。PDF作業プロジェクトの保存後は確認が出ず、再編集すると再び確認が出る
- ホームでカード編集とPDF翻訳の目的・主要機能を確認でき、それぞれの開始ボタンから対応画面へ移動できる
- ホームでは共通ナビゲーションが表示され、カード編集とPDF翻訳の選択肢が判別できる
- カード編集とPDF翻訳ではホーム用ヘッダーが表示されず、ツールバー左端の作業切替メニューで現在の作業を判別し、相互移動またはホームへ戻れる
- カード編集内の「カード」「アセット」は共通ナビゲーションと別の階層に表示され、プロジェクト未選択時は開始に不要な無効ボタンが並ばない
- カード編集の診断ログは「ツール」から開け、ツールメニューが右側タブより手前に表示され、件数表示、ログ消去、モーダルを閉じる操作ができる
- カード編集の操作が多い場合もツールバーは折り返さず、一段のまま横方向にスクロールできる
- プロジェクト読込後の上部ツールバーには保存とUndo／Redoが表示され、プロジェクト変更、CSV、用語集、翻訳設定は「ツール」から実行できる
- 右側の「領域一覧」「領域」「OCR」「翻訳」「印刷範囲」が排他的に表示され、各タブで右パネル全体の高さを使用できる
- 一覧で領域を選ぶと直前に使っていた編集タブへ移動し、初回は翻訳、OCR開始時はOCR、マスク編集時は領域が表示される
- 一覧の鉛筆ボタンから領域名を編集でき、Enter・フォーカス移動で確定、Escapeでキャンセルできる。名前変更はUndoで戻せる
- 領域一覧の×を押すと領域名を含む確認画面が表示され、キャンセルでは維持、削除では元テキスト・訳文・設定を含む対象領域だけが削除される
- 狭い画面でも作業切替メニューがツールバー左端に残り、カード編集とPDF翻訳の選択肢へ移動できる
- 空フォルダを選択し、最初のカード画像を開いてプロジェクトを保存できる
- 領域、保護領域、手動マスク、OCR辞書、アセットを追加して保存し、開き直してすべて復元される
- 複数カードを追加し、カードを切り替えても各カードの画像と領域が混ざらない
- カードAを編集してUndo／Redoした後にカードBへ切り替え、再びカードAへ戻って保存・再読込しても、画面の最終状態と保存結果が一致する
- 多数のカードを含むプロジェクトを開くと選択中カードが先に操作可能になり、カード一覧をスクロールした範囲と少し先のサムネイルだけが順次表示される
- カード追加・初回保存後に`thumbnails/<カードID>.jpg`が生成され、再読込で利用される。`thumbnails/`を削除した旧プロジェクト相当でも一覧表示時に元画像から再生成される
- サムネイルファイルを破損させて開くと元画像から再生成され、カード削除を保存すると元画像と対応サムネイルだけが削除される
- 画像と非画像とサブフォルダを含むフォルダから、直下のPNG / JPEGだけがファイル名順で追加される
- 複数カードの一括PNG / JPEG保存で削除予定を除く全カードが一覧順の連番名で出力され、終了後に元のカードへ戻る
- カードAとカードBをそれぞれ編集して往復し、各カードでUndo／Redoするとそのカード自身の操作履歴だけが復元される
- カードを削除予定にして取り消せる。保存後は対象画像だけが削除される
- 2回目以降の保存前データが`project.backup.json`へ残る
- version 0、version省略、version 1のプロジェクトを開き、保存するとversion 2になり、カードと領域が維持される
- カード名を一覧内で変更し、上下へ並べ替えて保存・再読込しても名称と順序が維持される
- 領域・カード順・アセット・フォント・OCR辞書・削除予定の変更で「未保存の変更あり」になり、保存成功後に「保存済み」へ戻る

## 印刷範囲とA4面付け

- 右側の「印刷範囲」で矩形を作成し、移動・四隅リサイズ・削除・カード全体への設定ができ、保存して開き直しても復元される
- 同寸法と異なる寸法のカードへ印刷範囲を一括適用し、画像に対する位置・大きさの比率が保たれ、個別に微調整できる
- PNG pHYs、JPEG JFIF／EXIFのDPIが自動表示され、DPIのない画像では手動入力するまでPDF保存が無効になる
- カード一覧に未設定・DPI未確認・設定済みが表示され、「PDF(A4)作成」でメイン作業領域へ移動できる
- 既定の3列で上から行単位に並び、行が残り高さへ収まらない場合は範囲を分割せず次ページへ送る
- 余白、列数、間隔、トンボを変更するとプレビューとPDFへ同じ位置・寸法で反映される
- PDFを「実際のサイズ（100%）」で印刷し、印刷範囲の縦横が元画像DPIから求めた実寸と一致する

## 背景補修

- 自動補修の「補修範囲を表示」で、元画像上の検出範囲だけが半透明の赤で表示される
- 自動判定、白文字、黒文字の各プリセットで対象文字の極性が切り替わる
- 検出強度と「色の外れ値を除去」の変更がプレビューと編集結果の両方へ反映される
- 保護領域の内側が自動・手動マスクの赤いプレビューと補修結果から除外される
- 手動マスクの追加ブラシと消しゴムが機能し、Undo / Redoで1ストロークずつ戻る
- 消しゴムを含む手動マスクを保存し、開き直して同じ補修結果になる

## OCR

- 複数行の英語領域をOCRし、候補が画像上の上→下の順で表示される

## PDF翻訳

- 複数ページPDFの解析中と翻訳PDFの書き出し中にページ進捗が表示され、「キャンセル」で処理が止まり、未完了PDFがダウンロードされない
- 100ページのPDFはそのまま解析を開始し、101ページ以上のPDFはページ解析前に件数つきの警告が表示され、「中止」と「読み込みを続ける」を選べる
- 捕捉可能なメモリ確保エラーでは、他のタブを閉じるかPDFを分割して再試行する案内が表示される
- パスワード付きPDFを選ぶと解除コピーを求めるエラーになり、フォーム・リンク・注釈を含むPDFでは種類別の件数と出力後確認の警告が表示される
- 画像ページで「範囲を選んでOCR」を有効にして文字部分だけをドラッグすると、その範囲だけの英語OCR結果が新しいtext_idでCSV対象へ追加され、CSV訳文を読み込むと同じ範囲だけが補修・置換される
- PDF作業をJSONへ保存して開き直し、同じ元PDFを選ぶと解析結果、翻訳、除外、保護領域、背景・文字色設定が復元され、異なるPDFでは指紋不一致エラーになる
- 90度・180度・270度回転またはMediaBoxと異なるCropBoxを持つPDFで、抽出枠・背景補修・訳文の位置と向きが元文字に一致する
- 日本語対応TTF / OTFを選んで翻訳PDFを保存し、PDFビューアーで日本語訳を検索・選択・コピーできる。フォント未選択時は同じ訳文を画像文字として保存できる
- PDF作業JSONを開き直した後はPDF用フォントが未選択になり、検索可能な文字で保存するにはフォントの再選択が必要になる
- プレビュー上の文字枠を選んでCSV対象から除外すると灰色表示になり、CSVと翻訳PDFに含まれず、対象へ戻すと再び含まれる
- 選択した文字枠の抽出原文を修正すると、同じtext_idと座標を維持したまま一覧とCSVへ反映され、既存の翻訳はクリアされる
- 選択した文字枠を「前へ」「次へ」で移動すると、同一ページ内の一覧順とCSV行順が変わり、text_idと座標は変わらない
- 選択した文字枠を次の項目と結合すると、先頭のtext_idを維持した1項目になり、両方の文字と範囲を含み、既存の翻訳がクリアされる
- 抽出原文を複数行にして分割すると、上から下へ行ごとの文字枠になり、先頭のtext_idと除外状態を引き継ぎ、既存の翻訳がクリアされる

## アセット編集

- 背景色を「外周から自動判定」と「色を指定」で切り替え、色入力とプレビュー上からの採色が透明化結果へ反映される
- アセット切り出し中の「透明にする」ブラシで、市松模様として見える透明部分が増える
- 同じ場所を「元に戻す」ブラシでなぞると、切り出し元画像の画素と透明度が復元される
- ブラシサイズ変更、「1画戻す」、「補正をクリア」がプレビューへ反映される
- ブラシ補正後に確定・保存・再読込し、カード編集プレビューとPNG / JPEG出力で同じ透過結果になる
- 登録後の左右余白を変更し、カード編集プレビューとPNG / JPEG出力でアイコン前後の間隔が一致する
- 登録済みアセットの「切り出し直し」で新しい範囲を確定すると、登録数とアセットIDを増やさず、表示倍率・上下位置・左右余白を維持したままプレビュー画像が置き換わる
- 新規登録と名前変更で同名アセットが拒否され、理由が対象入力欄の近くへ表示される
- 訳文へ未登録の`[icon:名前]`を入力すると、未登録名が警告され、Canvasではトークンが文字列のまま残る
- 文字タブから同じアセットを訳文へ2回挿入し、「訳文内で使用中」の1個目と2個目を選んで異なる倍率・上下位置・左右余白を指定すると、Canvas上でそれぞれ別の設定になる
- アセット個別設定を含むプロジェクトを保存・再読込し、対象の出現箇所とCanvas描画が復元される
- 個別設定より前の文字を編集、または同名トークンを保ったままCSVを再反映すると設定が対応する出現順へ追従し、対象トークンを削除すると個別設定もなくなる
- 個別設定済みアセットの名前を変更すると、全カードのトークンと個別設定が維持される

## 翻訳領域の表示

- 「編集結果」では未選択の翻訳領域にも控えめな点線枠が表示され、選択すると青い実線枠と四隅のハンドルへ切り替わる
- 「元画像」では未選択領域の点線枠が表示されず、PNG / JPEG書き出しにも領域枠が含まれない

## 複数カード

- カード一覧の領域・原文・訳の件数が、領域追加と原文・訳文編集に追従する
- カードを切り替えても各カードの件数が混ざらず、未入力は0件、領域がない場合は「—」で表示される
- 翻訳CSV読込後は即時反映されず、適用件数、未一致、重複、原文差異が行番号付きで表示される
- CSV照合画面のキャンセルでは訳文が変わらず、「反映」で一致した行だけがカードをまたいで更新される
- 上部のCSV保存では全カード、カード操作メニューの翻訳CSV保存では対象カードの領域だけが出力され、カード単位CSVを現在カードへ再読込できる
- 訳文の入力・CSV反映・自動翻訳で領域が「下書き」になり、空にすると「未翻訳」、手動選択で「確認済み」になる
- 新規領域の縦位置は「中央」になり、「上・中央・下」を切り替えると複数行、インラインアセット、保護領域を含む訳文が領域内で対応する位置へ移動する
- フォントサイズ直下の「領域内に収まるよう自動調整」は新規・旧データで有効になり、有効時は入力値を上限として縮小、無効時は入力したサイズを維持して領域外をクリップする
- 縦位置を保存してプロジェクトを開き直すと設定が維持され、縦位置を持たない旧プロジェクトは「中央」で表示される
- 保存・再読込後も領域ステータスが維持され、旧プロジェクトでは訳文の有無から未翻訳または下書きが補完される
- 領域一覧で表示名、CSV ID、原文、訳文を検索でき、ステータスフィルターとの組み合わせで対象だけが表示される
- カード一覧のプロジェクト内検索で別カードの領域を選ぶと、そのカードを読み込んで該当領域の文字編集が開く

## セキュリティ境界

- `=1+1`、`+cmd`、`-1+1`、`@SUM(...)`で始まる原文と訳文をCSV保存し、Excel、Google Sheets、LibreOfficeで数式として実行されない
- 上記CSVをHappyLocaleへ読み戻すと、原文と訳文から安全化用の接頭辞だけが除かれて元の値へ戻る
- 静的公開版（`pnpm build:static`で生成）で翻訳設定、接続確認、文字タブの翻訳ボタンが表示されず、Translation Endpointへの通信が発生しない
- 上限超過の画像、PDF、CSV、`project.json`、フォントを選ぶと具体的なエラーが表示され、その後に正常な別ファイルを選び直せる
- `images/`外のカード画像パスまたは`assets/`外のアセット画像パスを含む不正な`project.json`から、利用者ファイルを削除できない

## キーボードとフォーカス

- Tab移動時にボタン、リンク、入力、選択欄、開閉項目のフォーカス位置が見える
- インスペクターのタブを左右矢印、Home、Endで移動できる
- カード操作メニューをEscapeで閉じられる
- カード編集で`Cmd/Ctrl+Z`、`Cmd/Ctrl+Shift+Z`または`Ctrl+Y`によりUndo / Redoできる
- テキスト入力中のUndo / Redoはエディター全体ではなく入力欄へ作用する
- 削除確認と翻訳設定を開いたとき、安全側のボタンへ最初にフォーカスする

## 既知のポインター操作

Canvas上での領域作成・移動・リサイズ、保護領域作成、マスク描画、アセット切り出しはドラッグ操作を前提としています。キーボードのみで座標を作成・変更する代替UIは未実装です。

## アセット保存と改名の回帰確認

- 保存済みアセットを再切り出しして保存し、開き直すと新しい画像が表示される。`project.json` の画像パスは更新され、置き換え前の画像ファイルは削除される
- アセットを削除して保存すると、`project.json` の定義と対応する `assets/` 内の画像が削除される。他のアセット画像は残る
- カードA・Bで同じアセットを使って訳文を編集し、AでUndoした後にBへ移動してアセットを改名する。両カードでUndo／Redoしても古いアセット名が復活せず、画像が表示される
- 再切り出し後にカードを追加し、保存フォルダを開き直して追加カードと新しいアセット画像が復元される
- 保存失敗は `tests/services/project-cards.test.ts` の障害注入テストで確認する。バックアップまたは `project.json` の書き込み失敗時に、保存済み画像とプロジェクト情報が変わらず、新しい一時画像だけが削除される

## ルビの文字間隔

- 1行の領域でルビを有効にし、間隔を `2`、`0`、`-4` pxに変更する。原文領域の上端とルビの文字下端（縁取り込み）の距離が変わり、負の値では領域に重なる
- フォントや縁取り幅を変更しても、行内余白によってルビが浮かない。長い訳の自動縮小、画像上端付近での表示も確認する
- PNG書き出しと編集画面でルビの位置が一致する
- 原文画像の文字位置が異なっても、領域の上端が同じならルビの下端が揃う。複数行に対するルビは今回の対象外
