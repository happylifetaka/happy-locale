# PDF文字翻訳ロードマップ

## 目的

PDF全体をページ画像へ変換せず、PDFが持つ文字情報をCSVへ出力し、翻訳済みCSVを戻して元PDF上の文字を差し替えます。スキャンPDFへ一括OCRは行わず、文字PDFと画像PDFを先に判定します。

- [x] 各ページを文字ページまたは画像ページとして判定する
- [x] 文書全体を文字PDF、画像PDF、混在PDFとして表示する
- [x] 文字項目を行単位にまとめ、安定した`text_id`を付ける
- [x] PDF専用CSVへ原文を出力する
- [x] 翻訳CSVを`text_id`で照合し、不一致・重複・原文変更を数える
- [x] 元PDFを維持し、対象範囲だけを覆って日本語訳を重ねる
- [x] 画像ページをCSV対象にせず、一括OCRしない
- [x] 独立した`/pdf`画面で画像カード編集と状態・保存形式を分離する
- [x] ページプレビューへ抽出文字枠と翻訳後の局所パッチを表示する
- [x] 矩形の保護領域に重なる文字を翻訳と背景補修から除外する

### 検証記録

- 文字PDF: 文字1ページ／画像0ページ、抽出2件
- 画像PDF: 文字0ページ／画像1ページ、抽出0件
- 混在PDF: 文字1ページ／画像1ページ、抽出1件
- 文字PDFの翻訳CSVを2件読み込み、595×842ptを維持した1ページの翻訳PDFをChromeから保存

## 利用フロー

1. 「PDFを開く」でローカルPDFを選ぶ
2. 文字ページ数と画像ページ数を確認する
3. 「文字CSVを保存」で文字ページの原文を保存する
4. CSVの`translation`列だけを翻訳・編集する
5. 「翻訳CSVを読み込む」でCSVを戻す
6. 反映数、不一致、重複、原文変更、PDF名不一致を確認する
7. ページプレビューで文字枠、背景補修、文字色を確認し、必要なら保護領域を追加する
8. 検索・選択可能な訳文が必要なら、利用条件を確認した日本語対応TTF / OTFを選ぶ
9. 「翻訳PDFを保存」で元PDFとは別のPDFを保存する
10. 画像ページは現在のPDF画面から画像編集へ自動転送しない。必要なページをPNG / JPEGとして用意し、既存の画像編集で必要な範囲だけOCRする

## PDF判定

ページのテキストレイヤーから空白以外の文字項目を取得できた場合は文字ページ、取得できない場合は画像ページとします。

- 全ページが文字ページ: `文字PDF`
- 全ページが画像ページ: `画像PDF`
- 両方を含む: `混在PDF`

画像に不可視OCRテキストが付いているPDFは文字ページとして判定されます。これは抽出可能な文字レイヤーが存在するためで、将来は画像占有率や文字の可視性も使って「OCR付き画像PDF」を分離します。

## CSV形式

```csv
pdf_name (readonly),page (readonly),page_type (readonly),text_id,original (readonly),translation
rules.pdf,1,text,p0001-t0001,Draw two cards.,カードを2枚引く。
rules.pdf,1,text,p0001-t0002,Discard one card.,カードを1枚捨てる。
```

- `pdf_name`: 誤ったPDFへの適用を検出するための元ファイル名
- `page`: 確認用ページ番号
- `page_type`: 現在はCSV行を持つページでは`text`
- `text_id`: ページ番号と抽出順から作る照合キー
- `original`: 抽出した原文。CSV適用時に変更を検出する
- `translation`: 利用者が編集する訳文

座標や文字サイズはCSVへ出さず、解析中のPDFデータとしてブラウザ内に保持します。「作業を保存」で解析結果、翻訳、除外設定、保護領域、表示設定をPDFプロジェクトJSONへ保存できます。再開時はJSONに続けて元PDFを選択し、SHA-256指紋が一致した場合だけ状態を復元します。元PDF本体はJSONへ含めません。

## 出力方式

元PDFを`pdf-lib`で読み込み、翻訳対象の文字範囲だけに局所パッチを重ねます。ページ全体は画像化しないため、対象外のテキスト、ベクター図形、画像、ページ寸法は元PDFのままです。

既定では文字範囲の周囲4辺から背景色と軽い質感を補間し、元の文字と補間背景の色差から訳文色を推定します。確認用に、白い背景パッチと黒文字へ固定する設定も選べます。

TTF / OTFを選択すると、そのフォントの使用文字をサブセットとして埋め込み、日本語訳を検索・選択可能なPDFテキストで配置します。フォントを選択しない場合は、従来どおりCanvasで描いた局所画像として配置します。選択したフォント本体はPDF作業JSONへ保存されないため、作業を開き直した後は再選択が必要です。

現在は次の制約があります。

- 元文字はPDF内部から削除せず、局所的な背景パッチで視覚的に隠す
- 埋め込みフォントを選ばない場合、日本語訳はCanvasで描いた画像になり検索・選択できない
- 選択フォントに訳文の文字が収録されている必要があり、フォントの利用・埋め込み条件は利用者が確認する
- 複雑な模様や文字に接する図形では補間跡が目立つ場合がある
- 文字自体が任意角度で回転する場合、縦書き、複雑な段組みの座標はずれる場合がある
- 翻訳文が長い場合は元領域に収まるよう縮小する
